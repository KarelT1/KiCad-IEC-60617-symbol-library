# KiCad-IEC-60617-symbol-library (`IEC 60617 LIB.kicad_sym`)
A small KiCad symbol library containing IEC-60617-style symbols for common industrial control components. It's designed around a 2.54 mm grid with semi-automatic component referencing. Feel free to edit/add new components as needed through the symbol editor. You can also favorite the library, so it shows up at the top of the component list. 

---

### Why?

I simply like KiCad much more than other electrical drawing software. It has a massive built-in library of electrical components, PCB design capabilities, many user-made libraries that you can download, a neat UI, and it is open-source and free software that is regularly updated.

However, I couldn't find a symbol library that contained all the industrial control symbols I needed, so I made my own.

## Symbols

* **Contacts:**
  * Contact (NO / NC)
  * Change-over contact
  * Delayed contact (NO / NC)
  * Delayed operate contact (NO / NC)
  * Delayed return contact (NO / NC)
  * Emergency stop contact
  * Position contact (NO / NC)
  * Push button (NO / NC)
* **Contactors and Relays:**
  * Contactor coil
  * Contactor contact (NO / NC)
  * Contactor power contact NO (1-pole / 3-pole)
  * Relay coil
  * Relay contact (NO / NC)
  * Thermal contact (NO / NC)
  * Time relay delayed operate coil
  * Time relay delayed return coil
* **Protection & Motors:**
  * Circuit breaker (1-pole / 3-pole)
  * Fuse
  * Motor induction 3-pole
  * Motor phase 3-pole
  * Motor protection
